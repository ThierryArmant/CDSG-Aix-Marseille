Synthèse

Chaque classe est rattachée à un établissement, un chef d'établissement, un ou plusieurs professeurs référents et une unité marraine. Cliquez sur une tuile pour filtrer les fiches.

Poser une question

Exemples : « Qui est le référent à Cassis ? », « Quelles classes sont parrainées par la BA 115 ? », « Combien de classes en projet dans les Hautes-Alpes ? ». L'assistant répond à partir des fiches et ouvre la fiche concernée.

Réponse avec recherche web
Réglages du service de réponse (facultatif)
Sans clé, la recherche fonctionne quand même : elle retrouve les fiches par mots-clés. Avec une clé, les réponses sont rédigées. La clé n'est jamais publiée : elle reste dans votre navigateur.

Les fiches

Une fiche par classe. Les classes marquées « à vérifier » n'ont pas donné de nouvelles récentes : leur statut reste à confirmer.

Modifier les fiches et lancer les recherches : réglage (une seule fois)
Pour que vos modifications soient enregistrées dans le dossier en ligne, le site a besoin d'un jeton GitHub (une seule fois, sur votre ordinateur) :
  1. Ouvrir github.com → Settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nom : « CDSG site » ; Repository access : Only select repositories → cdsg-aix-marseille.
  3. Permissions → Repository permissions → Contents : Read and write et Actions : Read and write. Générer, copier le jeton.
  4. Le coller ci-dessous. Il reste dans ce navigateur uniquement.
Sans jeton, le bouton « Enregistrer » télécharge le fichier classes.js mis à jour, à déposer dans le dossier data du dépôt.

Actualités des classes

Dernières sorties, cérémonies, conventions, distinctions et articles de presse repérés en ligne. Mise à jour automatique chaque nuit. Cliquez pour lire.

Signaler un article
Un article, un PDF, une page de palmarès ou une publication sur une classe défense ? Collez le lien : l'assistant le lit, trouve la ou les classes concernées et range les informations dans leurs fiches (prochaine recherche, ou la nuit).

Méthode

Les fiches reprennent le tableau de suivi tenu par l'équipe des formateurs. Une classe est dite active quand une convention est signée et que rien n'indique un arrêt ; en sommeil quand la classe est abandonnée, sans référent ou sans unité marraine ; en projet quand l'établissement prépare une ouverture. Les compléments trouvés sur les sites publics (sites d'établissements, presse locale, communication des unités) sont signalés dans chaque fiche et restent à confirmer auprès des établissements.
